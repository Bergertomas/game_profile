## Core correction

The current artifact is contract-correct but not visually complete. Its
homepage remains a text-first contents page. The governing homepage decision is
a **compact art-led, utility-first entrance to a profile-first Field Guide**.
Authentic game identity should be evident in the first viewport while Search,
Compare and What should I play? retain their locked hierarchy.

The new work must be canonical public screens, not another long reconciliation
document with screens buried among prose.

## Credit-conscious sequence

### Gate A — visual direction acceptance

Create one recommended cohesive direction in a new project file named
**Should I Play - Canonical Screens**. Do not create three unrelated concepts.

Produce only:

1. validation-corpus homepage, desktop;
2. the same homepage at 390px;
3. one normal art-led profile, desktop and 390px;
4. the same profile's deliberate artless state, desktop and 390px;
5. a compact token/material note sufficient to explain the composition.

These screens must demonstrate:

- compact authentic artwork in the opening viewport without a full-height game
  takeover;
- Search as the dominant action, Compare as major secondary and What should I
  play? as progressive discovery;
- profile-first library/shelf continuity below the entrance;
- Archivo + Newsreader, graphite/warm paper, ruled hierarchy, zero-radius/
  hairline grammar and restrained game-led accent color;
- a recognizably authored Field Guide rather than SaaS, storefront, magazine,
  neon HUD, glass, bento/card soup or generic AI styling;
- real crop, focal-point, text-contrast and mixed art/artless behavior;
- no overall score, ranking, match percentage or universal winner;
- realistic copy hierarchy, not lorem ipsum.

Use only existing project/baseline art that already supported private design
evaluation, approved/cleared assets, or clearly labelled **PRIVATE DESIGN-ONLY**
official promotional material. Do not make a production rights claim. Preserve
the complete artless fallback.

Stop after Gate A for Tomas's visual-direction review. Do not spend credits on
the remaining screens if the foundational composition is not accepted.

### Gate B — canonical route set

Run only after Gate A acceptance. Extend the accepted direction into:

1. approximately-100-profile homepage, desktop and 390px;
2. global Search overlay/sheet with published, recognized-unprofiled,
   ambiguous, unrecognized and error states;
3. What should I play? entry, interpretation, criteria editing, verified/near/
   trade-off/indeterminate/no-match results and refinement;
4. Game Profile normal, provisional/range and materially scoped states,
   including time, storefront, trust, corrections and Compare exits;
5. Compare launcher and populated result, desktop and 390px, exactly two and
   artwork-free;
6. About/methodology/accountability presentation;
7. the material loading, empty, stale, long-title, mixed-art and no-JS states;
8. concise component, token, spacing, breakpoint and behavior handoff.

Reuse the repaired artifact's state logic and copy contracts. Do not invent new
product semantics while drawing screens.

## Gate A acceptance questions

Tomas should be able to answer yes to all of these before Gate B:

- Does the first viewport immediately feel like a product about games?
- Is it genuinely art-led while utility still dominates the interaction?
- Is Search unmistakably first without turning the page into a search engine?
- Are Compare and What should I play? present in the correct hierarchy?
- Does the profile feel emotionally tied to its game while remaining one
  coherent Should I Play? system?
- Does the artless version feel intentionally designed rather than broken?
- Is the result recognizably the agreed Field Guide direction?
- Does it avoid generic AI/vibecoded aesthetics?

## Prohibited changes

Do not change or reopen:

- brand/method identity;
- eight dimensions or scoring method;
- no-aggregate rule;
- journey names or hierarchy;
- catalog milestones;
- Search availability states;
- deterministic discovery semantics;
- Compare's exactly-two, differences-not-winners or artwork-free rules;
- canonical profile/scope routes;
- time/session bands;
- evidence/confidence/provisional truth;
- current self-funded/no-affiliate posture;
- public-first roadmap sequencing;
- personalization deferral.

If a visual composition exposes a real contract ambiguity, annotate it for the
owner instead of silently deciding it.
